# ImobPrime - Site Imobiliário Completo

Site imobiliário completo com 3 temas diferentes (Moderno, Clássico, Luxo), filtros avançados, sistema de favoritos, comparação de imóveis e muito mais.

## Recursos

- 12 imóveis de exemplo com fotos, descrições e preços
- 3 temas com troca em tempo real
- Filtros por tipo, finalidade, preço e quartos
- Sistema de favoritos
- Sistema de comparação de imóveis
- Modal com galeria de fotos
- Formulário de contato
- Design responsivo

## Estrutura

```
site imobiliario/
├── index.html
├── css/
│   ├── styles.css
│   └── themes.css
└── js/
    ├── data.js
    └── main.js
```

## Como usar

1. Edite `js/data.js` para adicionar ou modificar imóveis
2. Personalize cores em `css/themes.css` (temas Moderno, Clássico, Luxo)
3. Altere textos em `index.html`

## Deploy

Este site é estático e pode ser hospedado no GitHub Pages.
